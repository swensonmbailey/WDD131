Overview

Purpose

The Purpose of this site is to build a website for my Read It BoM content (YouTube, TikTok, Twitter, etc.). My content is focused on musing of Latter-day Saint related topics: scripture, history, fun facts, apologectics. I want a place for my audience to be able to see my recent content and have links to my social media profiles, so they can follow me there.

Audience

My audience is anyone intested in the Book of Mormon and the Church of Jesus Christ of Latter-day Saints. More specifically those who are intersted in apologectic answers and defenses for both the Book of Mormon and the Church. Anyone intested in learning about the restoration will be interested in my content.

Dynamic elements

On the home page there won't be any javascript.

On the content page there will be three main javascript uses. 1. The content (ie videos/lives/collabs) will be able to be filtered, so that the user can navigate more easily through the different kinds of content. 2. There will be a search function so that the user can quickly search to see if a video matches a word or phrase they are looking for. 3. Each video/live/collab has a description. These descriptions can be quite long. Default, using Javascript, only a protion of the description will be visible. There will be a "read more" button, that when pushed will cause the rest of the description to appear so the user can read it.

Pre-1832 Supporting Evidence for the Firsthand First Vision Accounts

Joseph Smith's First Vision was his first heavenly visitation in which he saw the Father and the Son. The first extant firsthand account of the vision appears in 1832. He later gave three other firsthand accounts of the vision. Critics try to say these accounts are conflicting or contradictory. This video provides all firsthand accounts plus two less known evidences, both of which are pre-1832, that support the different Firsthand Accounts and show that the first vision wasn't made up later on.
